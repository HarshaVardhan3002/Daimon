# Daimon

Daimon is a general-purpose assistant for Android, built with Expo and React Native. It supports text conversations, image input, generated images, quizzes, and text extraction from PDF, TXT, and Markdown attachments.

The app stores chats and drafts locally. In development, an optional loopback proxy provides model access; production service and release hardening remain separate work.

Run `npm install`, then `npm start` to launch the Expo development server. Run `npm test` for the focused proxy and state tests, and `npm run typecheck` for TypeScript validation.
